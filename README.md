# SKIPD™ — AI Customer Service Agent & Shopify Storefront

A working customer service AI agent and interactive Shopify storefront mockup built for the **SKIPD Screening Assignment** (Task 4: Customer Service Bot & Task 1: Channel Strategy).

## Features
- **Skipcare™ Aesthetic:** Clean, minimalist UI matching SKIPD's brand identity (Warm Sand, Terracotta, Deep Espresso, and Plus Jakarta Sans typography).
- **15+ FAQ Grounding:** Direct, informed, inclusive answers covering Glowscreen SPF 50+, Moonscreen Balm, formulations, routines, and shipping policies.
- **Brand Guardrails:**
  - Zero medical claims or fairness promises.
  - Multi-intent routing for routine recommendations (AM/PM sticks).
  - Cultural fluency in Hinglish queries.
- **Human Handover System:** Automatic trigger on adverse reactions (rashes), pregnancy questions, or refund disputes, collecting customer Name, Email, and Order Number for founder escalation.
- **Interactive Quick-Test Bar:** Built-in drawer to test all 10 evaluation questions live with simulated typing delays.
